### 2. 트러블 슈팅 (에러 해결 과정)
* **문제:** 터미널 상태가 '(venv) PS C:\work_LLM>' 에서 하위 폴더로 진입이 안됨
* **원인:** 'venv' 폴더 안에 'chap0_03' 작업 폴더가 저장됨
* **해결:** 'chap0_03' 폴더를 'venv' 폴더 밖으로 꺼내고, 터미널 창에서 'cd chap0_03' 입력하여 해결함.
* **참고:** 'venv' 폴더는 파이썬 실행 도구와 라이브러리를 저장하는 가상환경이므로, 작업 폴더(소스코드)는 'venv' 안에 저장하면 안 된다는 점을 깨달음.
